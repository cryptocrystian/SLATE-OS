# SLATE MVP Scope

## MVP Objective

Build the smallest version of SLATE that can reliably support:

> AI Workflow Scorecard → Lead Qualification → AI Opportunity Sprint → Audit Report → Proposal / SOW

This is the commercial wedge and first operating layer.

The MVP should prove the core workflow, establish the visual foundation, and create a premium product experience that can be extended over time.

---

## In Scope for MVP

## External-Facing

- Public AI Workflow Scorecard
- Scorecard completion flow
- Prospect result generation
- Lead capture
- Diagnostic review CTA / routing
- Stakeholder intake link
- Stakeholder guided intake form
- Document upload placeholder or simple upload UI

## Internal-Facing

- SLATE app shell
- Command center dashboard
- Lead dashboard
- Lead detail page
- Internal fit scoring display
- Company/account profile
- Contact and stakeholder records
- Engagement creation
- AI Opportunity Sprint engagement workspace
- Stakeholder intake sending and tracking
- Document review workspace
- Generated insights/findings workspace
- Opportunity scoring workspace
- Roadmap builder
- Audit report assembly
- Proposal / SOW generation support

## AI-Supported

The MVP may use mock AI outputs initially, but the UX should support eventual AI-assisted workflows:

- Scorecard analysis
- Stakeholder response synthesis
- Opportunity suggestion generation
- Impact/complexity scoring assistance
- Draft audit section generation
- Proposal draft generation

## Human Review

Human review is mandatory for important outputs.

The MVP must support:

- Manual approval/edit/reject of findings
- Manual finalization of report sections
- Manual adjustment of opportunity scores
- Manual approval of proposal/SOW options

AI outputs must never feel final by default.

# Out of Scope for MVP

- Full client portal
- Full venture studio operating layer
- Full BuildOps project management layer
- Billing / invoicing
- Time tracking
- Deep project management replacement
- External SaaS productization
- Complex role permissions matrix
- Automated implementation execution
- Full benchmarking engine
- Advanced analytics dashboards
- Fully automated final reports without review
- Production AI orchestration beyond placeholders unless explicitly prioritized
- Production auth unless needed for deployment/demo

# Future But Not MVP

## BuildOps

Development pipeline and AI-assisted code session management: project command center, context hub, sprint pipeline, canon doc manager, Claude/Codex session tracker, handoff prompt generator, QA workspace, deployment visibility.

## StudioOps

Venture studio operating layer: thesis cards, portfolio dashboard, validation tracker, product experiment tracker, studio build pipeline, case study generator.

## ClientOps

Ongoing client success and expansion: retainer tracking, monthly reports, QBR builder, expansion recommendations, client health scores.

---

# MVP Standard

The MVP should feel focused, polished, fast, trustworthy, useful, and premium enough to support the Saipien Labs brand.

The MVP should not feel like an admin template, AI wrapper, half-finished internal tool, generic CRM, form builder, or spreadsheet replacement.
