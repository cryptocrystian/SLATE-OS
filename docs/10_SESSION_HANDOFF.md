## Non-Negotiables

- Do not drift from the canon.
- Do not build BuildOps yet.
- Do not build StudioOps yet.
- Do not build billing, time tracking, or full project management yet.
- Do not build real AI orchestration yet unless explicitly instructed.
- Use mock data first.
- Prioritize premium UX and strong information architecture.
- Do not make SLATE look like a generic admin dashboard.
- AI outputs must be reviewable and clearly labeled when introduced.
- Preserve future extensibility.

## Design Standard

SLATE should feel:

- Premium
- Dark-mode native
- Product-grade
- Calm
- Precise
- Technical
- Trustworthy
- Human-guided
- Visually aligned with Saipien Labs

## Current Do-Not-Touch List

Do not implement these yet:

- BuildOps routes
- StudioOps routes
- ClientOps routes
- Auth
- Production database
- Billing
- Real AI APIs
- Multi-tenant SaaS productization
- Complex permissions
- Production export system
